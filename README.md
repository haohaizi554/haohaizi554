## Featured Project

### [UniversalCrawler](https://github.com/haohaizi554/UniversalCrawler)

A multi-platform crawler and downloader project built with Python.

- Supports crawler workflows for platforms including Douyin, Kuaishou, Bilibili, and Xiaohongshu.
- Provides multiple usage surfaces: GUI, WebUI, and CLI.
- Uses browser automation and HTTP parsing to extract structured content and media resources.
- Handles real-world instability through retry strategy, resilient DNS fallback, CDN route awareness, and task-level failure isolation.
- Separates platform spider logic, shared runtime utilities, downloader strategy, and task metadata.
- Designed as an explainable engineering project: architecture, tradeoffs, error handling, and test strategy can all be discussed in interviews.

> Good crawler engineering is not only about getting data once. It is about surviving unstable pages, expired links, network failures, and platform changes with a system that can still be reasoned about.
