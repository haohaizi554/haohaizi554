## About

Computer Science and Technology undergraduate. Focused on **backend engineering**, **crawler systems**, and **web automation**.

Main project: [**UniversalCrawler**](https://github.com/haohaizi554/UniversalCrawler), a Python crawler/downloader for Douyin, Kuaishou, Bilibili, Xiaohongshu and other platforms, with GUI, WebUI, and CLI support.

## Core Work

```text
Crawler Systems      browser automation, DOM parsing, request replay
Download Pipeline    retry strategy, CDN fallback, task metadata
Reliability          resilient DNS, logging, failure isolation
Product Surface      PyQt GUI, WebUI, CLI
```
